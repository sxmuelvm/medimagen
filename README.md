# Medimagen

Sistema de gestion y agendamiento de citas medicas.

## Local
python -m env venv
env\Scripts\activate
pip install -r requirements.txt
cd my-app
python run.py
Aplicacion: http://localhost:5001

## Docker
docker compose up --build
Aplicacion: http://localhost:5001
Workbench: 127.0.0.1 puerto 3007, usuario root
